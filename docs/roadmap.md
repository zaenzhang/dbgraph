# DbGraph Roadmap

更新：2026-10-21。最初审查基线为 `3c6a730` / workspace `0.1.2`；A 类已完成修复验收，`v0.1.4` 已发布，官网已更新。

本文取代建项时按 v0.1–v1.0 划分的阶段设想；原任务编号用于定位原始需求，不代表当前完成状态或发布版本承诺。

详细依据见 [AI 提效审查](ai-efficiency-review.md)，分三类维护：**A 项目自身 bug、B 外部项目已实现优点、C 外部 issue 痛点与建议**。本轮已完成 A 类 F01–F10 的修复、必要边界测试及本地/云端验证；见 [三轮审查后的修复计划](bug-fix-plan.md)。B/C 类与 I 类扩展建议保留为后续候选，按用户最新指示在发布后继续暂缓，未派发云端任务。修复验收与发布状态以计划和审查的验证记录为准。

## 当前基线

- 已有 PostgreSQL/SQLite snapshot、SQL 扫描、统一对象模型、本地 SQLite 图存储与 FTS、CLI/MCP、context/diff/impact/analyze、语义元数据与受控采样。
- MySQL/SQL Server 仍是 unsupported 占位实现。
- 已有安装脚本、发布 workflow 与离线 benchmark；全部平台安装、实际性能和真实 Agent 收益尚不能据此推定。
- 修复前基线为 135 个现有测试通过；隔离 SQLite 冒烟仍发现 SQL 误判、预算失效、检索退化和快照恢复问题。PostgreSQL live 测试当时未连接服务，不能算真实服务验收。

## 本轮已修复：可靠的 SQL 事实与判断

对应 A 类 F01/F02/F09。主要 owner：`dbgraph-sql`，CLI/MCP 和 graph analysis 消费共享结果。

- 补齐 SELECT 输出列、UPDATE 赋值、EXISTS 子查询等已复现漏检。
- 保留限定名和作用域，不能拿其他表同名字段证明引用有效。
- 统一 CLI/MCP 的语法、引用、整体结果与不完整分析语义。
- 用 AST 层级判断 DML 条件，不将子查询 WHERE 当作外层限制。

停点：已复现反例、合法对照、作用域边界通过；不扩展为所有方言的完整优化器。

## 本轮已修复：成功采集与可恢复的索引

对应 A 类 F05–F08。主要 owner：SQL artifact 身份、CLI snapshot 编排、core snapshot 与 storage 事务。

- 分开文件来源身份与 workload fingerprint，支持多文件相同 SQL。
- 仅完成的 capture 发布为 latest，失败不发布未完成事实。
- schema 未变化但索引缺失时恢复，不虚报 sync 成功。
- 无历史基线时 diff 明确说明，不比较自身。

停点：重复来源、失败发布、缺索引、零/一/多快照边界通过。JSON 仍为事实源，SQLite 是可重建索引，不增加平行状态系统。

## 本轮已修复：更少调用、更小且可核对的上下文

本轮仅修 A 类 F03/F04。主要 owner：graph search/context 与 MCP 输出。

- Unicode、短标识符、无匹配返回空；复用 semantic，不硬编码业务词汇。
- 预算覆盖完整输出，使 maxResponseChars 真正生效。
- 更丰富的匹配依据、snapshot 来源、覆盖说明与后续查询建议属于 I03/B/C 候选，本轮不增加。

停点：中英文相关样例召回正确，无匹配不产生假答案，完整输出受控，预算不足明确报错。不把词法检索承诺成跨语言语义理解。

## 暂缓：用任务与性能评测决定下一轮投入

对应审查的任务转化建议 I01/I02，检索语料覆盖 C03，复杂 SQL 语料覆盖 C04。以下是后续候选，不在当前修复范围内。

- 建 SQL 修错、影响分析、中文定位、无答案、恢复任务集，期望答案只给评分器。
- 记录正确率、错误自信、实际工具调用、重试、累计响应体积、冷/热延迟。
- 测实际建图/search/context，依据瓶颈使用已有 FTS 或对象映射。
- 在线模型对照另行明确模型、成本、重复运行方案；离线压缩率不宣称实际费用节省。

停点：有可复现任务结果与性能基线再决定基础设施，不预设向量库或常驻缓存。

## 交付保障与条件性扩展

- F10：release workflow 补充 `macos-15-intel` 的 macOS x64 构建，与已有六平台安装合同一致；六平台构建/资产发布已通过，Windows x64 下载包冒烟通过；其他原生运行与安装器验收仍单列为未验证。
- CI 曾在 `6c6e8cf` 主动改成 tag-only。本轮只补发布平台，不更改触发策略；轻量 PR 或手动预发布门禁留待明确成本策略后决定。
- MySQL/SQL Server 仅在明确业务需求阻塞时提前；沿用统一 snapshot，要求真实服务验收，不以注册 provider 作为完成。
- 云端索引、向量库、完整 Web 管理台和模型直接执行业务写 SQL 暂不进入优先队列。
